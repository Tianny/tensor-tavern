# Claude Code 工程化实战

## 课程简介

本教程系统性地介绍 Claude Code 的高级功能和工程化实践。帮助你从"会用 Claude Code"提升到"精通 Claude Code"做项目。

## 章节概览

| 章节 | 主题 | 核心内容 |
|------|------|----------|
| 02 | Memory | CLAUDE.md 记忆系统 |
| 03 | SubAgents | 子代理与任务分发 |
| 04 | Plugins | 插件开发与分发 |
| 05 | Commands | 自定义斜杠命令 |
| 06 | Skills | Agent Skills 能力包 |
| 07 | Hooks | 钩子与自动化控制 |
| 08 | MCP | 外部工具集成协议 |
| 09 | Headless | CI/CD 与自动化 |
| 10 | Agent SDK | 编程式 Agent 开发 |
